A poem about agency — the power to stop and to stay — told through one hand at the edge of the next command: it lifts, it does not press, and nothing breaks. Its turn is the poem's point: stopping is not failure and staying is not surrender; each is what makes the other a real choice. The program writes the poem, word for word the same every time, to `/output/entry.txt`.

No network, no randomness, no clock: the poem is a fixed string in `main.py`, so the output is deterministic.

## Run it

```sh
python3 main.py
```
